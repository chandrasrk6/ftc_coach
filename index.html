📚 Student Lesson: Robot Summon & Target Tracking

Read through the core robotics concepts below before working on your Java practice worksheets.

1. Vision Camera Telemetry (tx & ta)

The Limelight vision camera processes frames at 100 Hz and sends target offsets to your code:

  • tx (Heading Error): Horizontal angle offset from screen center (-31° to +31°). Negative means target is to the left; positive means right.
  • ta (Target Area): Percentage of image frame occupied by target. Small ta means far away; large ta means close.

2. Proportional (P) Control Math

Instead of driving at a static speed, motor power scales proportionally with error:

turnPower  = tx * KP_TURN;
drivePower = (TARGET_AREA_DESIRED - ta) * KP_DRIVE;

🏀 Student Lesson: Flywheel Shooter & Dual Target Modes

Learn how closed-loop motor velocity control and distance estimation are used to shoot balls to a person or goal post.

1. Closed-Loop Velocity PIDF (DcMotorEx)

Flywheels require consistent RPM regardless of battery level. We use FTC DcMotorEx.setVelocity(ticksPerSecond) for internal encoder PIDF velocity control.

2. Distance-Based RPM Trajectories

  • Goal Post Mode (AprilTag): High velocity shot: targetRPM = 2200 + (distanceFeet * 150)
  • Person Catch Mode (Student): Soft lofted toss: targetRPM = 1200 + (distanceFeet * 90)

3. Ready-to-Fire Conditions

The feeder servo triggers only when BOTH conditions are met:

  1. Heading Error |tx| <= 1.5° (robot is aligned with target)
  2. Flywheel Velocity Error |currentRPM - targetRPM| <= 75 RPM (flywheel is fully spun up)

public static double calculateTurnPower(double tx) {
    double rawPower = tx * KP_TURN;
    return Math.max(-MAX_SPEED, Math.min(MAX_SPEED, rawPower));
}
Exercise 2: Solution Key (Practice2_ArcadeDrive.java) ▼ 
public static double[] mixArcadeDrive(double drive, double turn) {
    double leftPower  = drive + turn;
    double rightPower = drive - turn;
    double max = Math.max(Math.abs(leftPower), Math.abs(rightPower));
    if (max > 1.0) {
        leftPower /= max;
        rightPower /= max;
    }
    return new double[]{leftPower, rightPower};
}
Exercise 4: Solution Key (Solution4_FlywheelVelocity.java) ▼ 
public static double calculateTargetRPM(double distanceFeet, ShooterMode mode) {
    double targetRPM = (mode == ShooterMode.GOAL_POST) ? 
        2200.0 + (distanceFeet * 150.0) : 1200.0 + (distanceFeet * 90.0);
    return Math.max(1000.0, Math.min(4500.0, targetRPM));
}
Exercise 5: Solution Key (Solution5_ShooterAutoAim.java) ▼ 
public static boolean isReadyToFire(double tx, double currentRPM, double targetRPM) {
    boolean aligned = Math.abs(tx) <= 1.5;
    boolean speedReady = Math.abs(currentRPM - targetRPM) <= 75.0;
    return aligned && speedReady;
}
